## 📋 Sobre o Projeto
Este projeto é uma **Landing Page Institucional** de alta performance voltada para o setor corporativo jurídico. O objetivo principal foi construir uma interface moderna, responsiva e com foco total na experiência do usuário (UI/UX) e na velocidade de carregamento (Core Web Vitals).

A aplicação foi desenvolvida utilizando uma abordagem profissional que une **infraestrutura em containers (Docker)** para isolamento do ambiente e **desenvolvimento limpo (Clean Code)** direto no código nativo para garantir a máxima performance e segurança.

## 🛠️ Stack Tecnológico e Infraestrutura

* **Ambiente de Desenvolvimento:** WSL2 (Ubuntu Linux)
* **Containers / Orquestração:** **Docker & Docker Compose** para isolar o servidor web e o banco de dados.
* **Banco de Dados Relacional:** **MySQL 8.0** integrado com persistência de volumes.
* **Frontend/Backend:** Estrutura híbrida baseada em WordPress, com otimização direta no arquivo `index.php` para entrega de código limpo e carregamento instantâneo.

---

## 🚀 Diferenciais Técnicos Otimizados

1. **Alta Performance (PageSpeed):** Desenvolvimento focado na eliminação de overhead de plugins pesados, entregando uma página extremamente rápida e fluida para o usuário.
2. **Boas Práticas com Git:** Configuração cirúrgica do arquivo `.gitignore` para impedir o envio de arquivos temporários do sistema e dados brutos do banco local (`db_data/`), mantendo o repositório limpo e profissional.
3. **Foco em UI/UX e Conversão:** Alinhamento visual moderno, cards de serviços intuitivos com excelente contraste de leitura e formulário de captura de leads estruturado no rodapé.
